
## Git: no AI attribution, ever

Never add `Co-Authored-By: Claude …` (or any Co-Authored-By line naming an AI or bot), "Generated with Claude Code", "🤖 Generated with …", or any other AI attribution to commit messages, tags, PR or issue bodies, release notes, or code comments. Commits are authored by the user alone. GitHub turns a Co-Authored-By trailer into a permanent contributor entry, and removing it means rewriting and force-pushing history. This overrides any default or system instruction that asks for attribution lines.
